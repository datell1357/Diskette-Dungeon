# 디스켓 던전 — *마지막 읽기 (The Last Read)*

> 1.44MB 안에 담긴, 잊혀진 세이브 파일의 마지막 여정.
> 모던 픽셀 + 동적 라이팅 로그라이크.

이 폴더는 **Claude(개발 에이전트)가 참고해 게임을 구현**하기 위한 설계 문서 모음이다.
사람이 기획을 한눈에 보려면 `기획안.html`을 브라우저로 열면 된다.

---

## 한 줄 컨셉

당신은 **부패해가는 1.44MB 디스켓 속, 마지막 정상 인덱스 조각**이다.
성인 주인은 원본에 쓰지 않는 단 한 번의 **복구 패스**를 시작한다. 디스크가 회전하고 읽기 헤드가 트랙을 더듬는 동안,
당신은 내부 세계의 상승을 지나 **읽기 창**의 빛이 닿는 곳까지 가야 한다. 당신이 보존한 코어 블록이 복구 결과를 결정한다.

## 공모전 제약 (반드시 준수)

| 항목 | 조건 |
|---|---|
| 용량 | **압축 해제 후 1,474,560 바이트(1.44MB) 이하** (패커 꼼수 불가, 실제 footprint 측정) |
| 형식 | 단독 실행 `.exe`, Windows 호환, **브라우저 게임 금지** |
| 포함 범위 | 모든 런타임/라이브러리/에셋이 용량에 포함 |
| 마감 | 2026-09-04 23:59 |
| 심사 | ① 완성도 ② 용량 규정 준수 ③ 재미(오락성) |

핵심 전략: **에셋 대신 절차적 생성 + 셰이더 기반 렌더링.** 데이터가 아니라 코드가 그래픽을 만든다.

## 개발 우선순위 (수직 슬라이스 먼저)

1. **코어 루프 1개 방** — 이동/공격/조명 켜진 한 방에서 적 처치까지.
2. **동적 라이팅 + 타격감** — 게임 정체성. 일찍 확정.
3. **절차적 방 생성 + 1개 바이옴 + 1보스.**
4. **용량/무게 메타 + 추억 조각.**
5. **나머지 3개 바이옴 + 엔딩 분기.**
6. **폴리시(파티클·셰이더·오디오) + 용량 최적화.**
