# 디스켓 던전: 마지막 읽기

> 1.44MB 디스켓에 남은 마지막 정상 인덱스 조각이, 원본에 기록하지 않는 단 한 번의 복구 패스를 따라 읽기 창으로 향하는 픽셀 액션 로그라이크.

**Diskette Dungeon: The Last Read**는 절차적으로 생성한 그래픽과 신스 오디오로 만든 Windows·macOS 실행형 게임입니다. 플레이어는 부패한 세이브 안의 작은 빛이 되어, 적을 물리치고 복구 블록과 기억을 보존하며 엔딩을 바꿉니다.

## 핵심 특징

- 4개 바이옴과 4개 보스, 무작위 방·분기 보상으로 구성된 한 번의 복구 런
- 밝아질수록 강해지지만 느려지는 빛과, 1440KB 복구 버퍼를 관리하는 빌드 선택
- 6종 무기, 일반 유물, 무기 전용 유물, 접두사 무기 변형
- 3단계 난이도, 시드, New Game+, 영구 해금과 캐릭터 강화
- 첫 실행 프롤로그, 복구 블록 회상, 보존한 블록 수와 난이도에 따른 4개 엔딩
- 메인 메뉴의 도감에서 몬스터·보스·무기·유물 정보와 이미지를 확인

## 시작하기

최신 실행 파일은 [Releases](../../releases)에서 받습니다.

- Windows: `DisketteDungeon-1.0.0-win64.exe`
- macOS: `DisketteDungeon-1.0.0-macos.zip` 압축을 푼 뒤 `DisketteDungeon.app` 실행

소스에서 빌드하려면 아래를 사용하세요.

```sh
# Windows 제출용 단독 실행 파일 (macOS/Linux에서는 mingw-w64 필요)
sh tools/build_win.sh

# macOS 개발/진단 빌드 (Metal)
DD_DEBUG_BUILD=1 sh tools/build_mac.sh
./build/DisketteDungeon_diag_mac
```

Windows 빌드는 용량 게이트를 자동 검사합니다. 자세한 빌드·진단 절차는 [BUILD.md](BUILD.md)를 참고하세요.

## 조작

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 |
| 마우스 / `Space` | 공격. 키보드 공격 시 가장 가까운 적을 자동 조준 |
| `Shift` | 대시 |
| `E` | 아이템 줍기·상호작용 |
| `Q` | 추억 조각 버리기 |
| `Tab` | 가방 열기 |
| `Esc` | 일시정지 또는 이전 화면으로 돌아가기 |
| 사망 후 `R` | 같은 시드로 즉시 재시작 |

무기 변경과 유물 교체 화면은 `W`/`S` 또는 방향키로도 선택할 수 있습니다.

## 빛과 복구 버퍼

빛의 조각을 모으면 플레이어의 광원이 커집니다. 광원이 클수록 이동 속도는 낮아지지만, 적에게 주는 피해가 증가하고 시작 실드를 포함한 실드 한도가 커집니다. 실드는 최대 체력 및 5칸 제한을 넘지 않으며, 다음 스테이지로 넘어갈 때 1칸 회복합니다.

무기·유물·추억 조각은 복구 버퍼(1440KB)를 사용합니다. 가벼우면 빠르고, 무거우면 빛과 전투력이 강해집니다. 버퍼를 비울지, 기억을 끝까지 보존할지 선택하는 것이 런의 핵심입니다.

## 무기 해금

포인터 블레이드는 기본 무기입니다. 다른 무기는 메인 메뉴의 **무기 변경**에서 바이트로 해금합니다.

| 무기 | 방식 | 해금 가격 |
|---|---|---:|
| 포인터 블레이드 | 근접 베기 | 기본 지급 |
| 비트 캐논 | 충전 포탄 폭발 | 130 바이트 |
| 패킷 스프레이 | 다발 산탄 분사 | 190 바이트 |
| 루프 글레이브 | 투척 후 귀환 | 230 바이트 |
| 널 랜스 | 직선 관통 창 | 200 바이트 |
| 에코 완드 | 유도탄 연속 발사 | 410 바이트 |

일반 유물은 최대 4개, 무기 유물은 최대 2개를 보유합니다. 한도를 넘겨 새 유물을 획득하면 교체할 유물 또는 현재 상태 유지를 선택합니다.

## 진행과 엔딩

바이옴 보스가 남기는 4개의 복구 블록을 읽기 창까지 가져가면 복구 결과가 정해집니다.

| 보존한 복구 블록 | 결과 |
|---:|---|
| 0개 | 지워짐 |
| 1~3개 | 한 번 더 |
| 4개 (쉬움/보통) | 완전 복구 |
| 4개 (어려움) | 진엔딩: 원본의 이름 · New Game+ 해금 |

첫 시작에서는 스킵할 수 없는 프롤로그가 재생됩니다. 이후에는 자동으로 건너뛰며, **설정 → 오프닝 다시보기**에서 한 번 다시 볼 수 있습니다.

## 설정과 도감

메인 메뉴와 일시정지 메뉴의 **설정**에서 배경음악, 효과음, 난이도, 화면 흔들림, 스캔라인(CRT 효과), 시드, 오프닝 다시보기, New Game+를 바꿀 수 있습니다. 난이도는 새 런을 시작할 때도 선택합니다.

**도감**에서는 몬스터, 보스, 무기, 유물을 고르고 각 항목의 수치·공격 방식·이미지를 확인할 수 있습니다.

## 세이브 위치

- Windows: `%APPDATA%\DisketteDungeon\save.bin`
- macOS: `~/Library/Application Support/DisketteDungeon/save.bin`

메타 진행만 저장하며, 진행 중인 런은 저장하지 않습니다.
